# jwave 仿真参数指南（场景 → 推荐参数）

> 面向 LLM 代码生成：根据用户场景直接给出可运行的参数组合。
> 数据来源：50 次回归实测 + VAL-1 验证基准 + validate_simulation_params 规则。
> 修改记录：2026-08-18 新建。

### 参数选择核心规则（先读）

1. **Nyquist（最优先）**：`dx ≤ λ/4`，`λ = sound_speed / frequency`。
   例：2 MHz 水中（c=1500）→ λ=0.75mm → dx ≤ 0.19mm。
2. **每波长网格数**：`N ≈ 域尺寸 / dx`，保证每波长 ≥ 8 点。
3. **CFL**：`cfl = 0.1`（稳定 + 峰值采样精度；上限 0.3）。
4. **PML**：`pml_size = 10~20`；物理区半径 = N/2 − pml_size。
5. **t_end**：`t_end ≈ 传播距离 / 声速`（波走完整域所需时间的量级）。
6. **3D 内存**：N ≤ 72，dx 用 0.5mm 量级，t_end 相应缩短。

### 场景 A · 2D 点声源（最常见）

| 频率 | 推荐 dx | 推荐 N | 区域尺寸 | t_end（c=1500） |
|------|---------|--------|---------|----------------|
| 0.5 MHz | ≤0.75mm | 128~192 | 1~2cm | 10~25µs |
| 1 MHz | ≤0.38mm | 128~256 | 1cm | 5~10µs |
| 2 MHz | ≤0.19mm | 160~256 | 0.8~1.2cm | 4~8µs |
| 3 MHz | ≤0.125mm | 192~256 | 0.8~1cm | 2.5~5µs |
| 5 MHz | ≤0.075mm | 224~256 | 0.8cm | 2~4µs |

示例组合：`f0=2MHz, N=200, dx=0.1mm（区域 2cm→200 格... 若区域 1cm 则 dx=0.05mm 或 N=100）`
——**优先满足 dx ≤ λ/4**，再定 N = 区域/dx。

### 场景 B · 高斯/环形/椭圆初始压力（p0）

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 峰值 pressure | 100~1500 Pa | 用户给则用；不给默认 1000 Pa |
| 高斯 σ | λ/2 ~ λ | 半宽至少 1 格，太小会欠采样 |
| 环形 R0 | < N/2 − pml_size | 超出会被 PML 吸收 → 全零 |
| 椭圆 a/b | < N/2 − pml_size | 同上 |
| 网格 | N≥160，dx 满足 Nyquist | 椭圆/环形需要足够分辨率 |

### 场景 C · 异质介质（囊肿/分层/组织）

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 背景声速 | 1480~1540 m/s | 按介质（水 1500、软组织 1540） |
| 病灶/囊肿声速 | 背景 ±10~20% | 低声速囊肿 1400~1450，高声速 1600~1800 |
| 病灶直径 | 1~4 mm | 至少覆盖 4~8 个网格 |
| 网格 | N≥192 | 异质边界需要分辨率 |
| 点源位置 | 病灶外（左侧/下方） | 避免源落在强异质边界 |

### 场景 D · 3D 仿真（P1 新增）

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| N | 48~72 | **72 是内存安全上限**（约 1.1GB） |
| dx | 0.5mm（300kHz）| 3D 用较低频控制 Nt 与内存 |
| f0 | 100~500 kHz | 高频 3D 内存爆炸 |
| t_end | 15~25µs | 相应缩短 |
| pml_size | 8~10 | 3D 内存受限，PML 取小 |

### 场景 E · 介质衰减（P1 新增，频域）

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 求解器 | `helmholtz_solver`（频域） | 时域忽略 attenuation |
| alpha_db | 0~10 dB（幂律 y=2）| >100 远场信号过弱 |
| f0 | 0.5~2 MHz | 频率越高衰减越强 |
| 探针距离 | 物理区内 | r ≤ N/2 − pml_size |

### 参数校验（validate_simulation_params 会检查）

- dx > λ/4 → 拒绝（提示减小 dx 或降频）
- cfl > 0.3 → 拒绝
- N < 32 → 拒绝；N > 1024 → 警告
- 3D：N³×Nt×4B > 3GB → 拒绝；> 1.5GB → 警告
- attenuation < 0 → 拒绝；> 100 → 警告；提示时域忽略衰减
- 环形/椭圆半径 ≥ 域半宽 → 拒绝（会全零）
